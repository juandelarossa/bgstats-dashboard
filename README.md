# 🎲 BG Stats Dashboard

Een vrolijk, gratis dashboard voor je **BG Stats-export**, inclusief je potjes op **Board Game Arena**.

**Open het dashboard:** https://juandelarossa.github.io/bgstats-dashboard/

## Zo werkt het

1. Speel je online? Importeer je Board Game Arena-potjes eerst in de BG Stats-app.
2. Maak in BG Stats een export of back-up als `.json`-bestand.
3. Open het dashboard en kies dat bestand (of sleep het op de pagina).

Je bestand wordt **alleen in je eigen browser** gelezen. Er is geen server en er wordt niets verstuurd.
Het dashboard onthoudt je gegevens op je eigen apparaat, zodat je ze niet elke keer opnieuw hoeft te kiezen;
met "Wis mijn gegevens van dit apparaat" haal je ze weg.

## Wat zit erin

- Scorekaart met winratio, reeksen, vorm en een prijzenkast
- **Hoe goed ben je per spel?** Gemiddelde eindplaats, hoeveel tegenstanders achter je eindigden, trend, winratio per aantal spelers en als startspeler
- Live tegen digitaal (Board Game Arena, Yucata, Tabletop Simulator) als filter op alles
- Genres, klassement, rivalen, speelpatronen, speelplekken en een logboek met links naar je BGA-tafels

## Wat er (nog) niet in zit

BG Stats neemt bij de import uit Board Game Arena geen speelduur, aantal zetten of tijd per zet mee.
Die cijfers staan alleen op Board Game Arena zelf en kunnen dus niet in dit dashboard.

## Over dit project

De code komt uit het persoonlijke scoreboard van de maker en wordt hier automatisch bijgewerkt.
Niet verbonden aan BG Stats, Board Game Arena of BoardGameGeek. Covers en spelgegevens komen van BoardGameGeek.
